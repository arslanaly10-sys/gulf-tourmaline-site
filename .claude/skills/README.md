# Project skills

Design, writing and front-end skills used to build the Gulf Tourmaline site and RFQ assistant.
All sources are MIT-licensed; licence copies are in `_licenses/`.

| Prefix / skill | Source |
| --- | --- |
| `web-design-guidelines`, `react-best-practices`, `composition-patterns`, `react-view-transitions`, `writing-guidelines`, `deploy-to-vercel`, `vercel-optimize` | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) (MIT) |
| `taste-skill` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) |
| `emil-*` | [emilkowalski/skills](https://github.com/emilkowalski/skills) (web-relevant subset) |
| `rs-*` (incl. `rs-motion` for animation principles) | [raphaelsalaja/skill](https://github.com/raphaelsalaja/skill) (web-relevant subset) |
| `uupm-*` | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) |

Not copied as skills:
- `docs/design-references/` holds the DESIGN.md write-ups from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) as reference reading (principles only, never to copy a brand).
- Icons: the `@phosphor-icons/react` package is used instead of the phosphor-icons homepage repo.
- Browser testing uses Playwright (pre-installed) rather than `microsoft/playwright-cli`.
- `frontend-design` and `graphify` are available as Claude plugin skills and are not vendored here.
- Mobile/Swift-only skills (e.g. `write-swift`, `animate-expo`, `react-native-skills`) were left out as irrelevant to a website.
